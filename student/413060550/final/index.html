第四階段 // 誰是共犯 (多維度視角)

一場沒有壞人的膠著共犯結構

移工的失聯，往往不是單一惡意造成的，而是社會結構與供需多方拉扯下的妥協。點選下方的系統角色，傾聽他們無可奈何的真實處境。

雇主的真實無奈 / Voice of Employer

「我這間金屬沖壓廠如果明天停工，我拿什麼交給德國跟美國的客戶？台灣年輕人來做半天就嫌熱不幹了，我不找失聯移工來應急，工廠明天就只能清算、倒閉。」

產業真實現狀：中南部中小製造業與急迫家庭面臨極限缺工困境。 衝突係數：★★★★☆
第五階段 // 日常中的微小挪步

修補斷網：我們可以展開的行動

制度不公龐大如網，但並非無法撼動。拉動下方的物理滑桿，解鎖我們可以從日常開始實踐的微小改變。

行動一 // 去標籤化

重置對話定義

SLIDE TO UNLOCK
從日常語言開始：不再以「逃跑移工」、「非法」等具有刑事定調含義的標籤看待他們。改用「失聯」或「非正式僱傭」來理解其因債務、不合理住宿限制所做出的被動生存選擇。

行動二 // 勞動改革

引進源頭改革

SLIDE TO UNLOCK
倡議 G2G 直聘與跨國取消私仲：持續關注並支持政府對政府直接引進（Government-to-Government）機制。逐步取消黑箱的「跨國私人仲介」，從源頭切斷逼使移工因承受暴利債務而必須逃跑的制度枷鎖。

行動三 // 科技賦權

匿名數位存證支援

SLIDE TO UNLOCK
運用不對稱科技保全證據：推廣匿名、基於加密雜湊機制的勞動證據蒐集鏈。當弱勢移工在地下黑市遭遇無良雇主剝削或突發職災時，能在第一時間不暴露行蹤地數位存證，作為日後 NGO 爭取權益的鐵證。
